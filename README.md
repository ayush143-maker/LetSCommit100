# LetSCommit100

A public collection of small, practical web experiments, built one commit at a time.

## First milestone: 100 commits

The goal is to build and improve tiny browser tools while keeping the history readable. Each commit should represent an actual addition, fix, improvement, test, or useful piece of documentation—not an empty change.

## Experiments

- `index.html` — a simple start page for the collection.
- `tools/` — small standalone HTML/CSS/JavaScript utilities.
- `notes/` — concise implementation notes and lessons learned.

## Run

Open any standalone HTML tool in a modern browser. Tools should avoid unnecessary dependencies and work without a build step where possible.

## Commit principles

1. Keep each change small and understandable.
2. Use descriptive commit messages.
3. Prefer accessible, responsive interfaces.
4. Document limitations honestly.
5. Test behavior before claiming it works.

## Milestones

- [x] Create the public repository.
- [ ] Build and verify the first 10 meaningful commits.
- [ ] Reach 25 useful commits.
- [ ] Reach 50 useful commits.
- [ ] Reach 100 useful commits.

A commit count is a progress marker, not a substitute for useful work.
